## 🎯 Sobre mim

Estudante de Tecnologia (IA/Data Science) na **FATEC Rio Claro**, com experiência prévia em suporte de TI, relatórios SQL e sistemas de gestão hospitalar (*Oracle Database, Tasy*).

Hoje me dedico a pipelines de machine learning de ponta a ponta, análise preditiva e desenvolvimento de aplicações inteligentes — desde motores de risco de crédito até sistemas de saúde pública.

- 🎓 **Foco de estudo:** Bancos de dados, mineração de dados, séries temporais e modelagem preditiva.
- 🧪 **Na prática:** Pipelines de ML completos, otimização de métricas com impacto financeiro, dashboards analíticos e trabalho colaborativo.
